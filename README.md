# mapamental-dev-python
Guia e Mapa mental para começar a aprender python do zero.
[ Para acessar o mapa mental, clique ->] (https://notebook.google.com/notebook/35dc8785-e888-4bd2-b6e1-f9d59203e9f9)


Contexto e Objetivos do projeto:
Criar um material de estudo junto à ferramenta NotebookLM para conseguir facilitar e acelerar o aprendizado de python para os alunos.
Explicando conceitos fundamentais da linguagem e propondo projetos para além de fortalecer o aprendizado, melhorar sua prática e portfólio.
Através de fontes em vídeo e PDF, foi finalizado  o mapa mental ramificado e explicativo.
